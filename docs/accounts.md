# 账号与调度

[文档导航](README.md) · [配置](configuration.md) · [控制台](console.md)

本页的设备登录、凭证目录与号池调度适用于 **WorkBuddy 国内版 / 国际版**。可将本人已授权的多个账号放入同一区域的号池，按健康度调度，并根据错误类型换号。账号池不会改变上游额度或权限。

OpenRouter 使用配置中的单个 API Key，Cursor 只读复用桌面个人 Free 登录态。控制台可展示它们的连接状态，但不支持 WorkBuddy 的添加账号、停用、清除冷却和设备码重新登录。认证与恢复方式见[平台支持](platforms.md)。

```bash
agent2api login -region cn -out auths/cn/account-a.json
agent2api login -region cn -out auths/cn/account-b.json
agent2api -platform workbuddy -accounts-dir auths/cn
```

也可以在控制台「账号管理 → 添加账号」中，直接选择 **WorkBuddy 国内版** 或 **WorkBuddy 国际版**，再点击「开始登录」完成浏览器授权（设备码登录）。两个入口分别对应 `workbuddy` / `workbuddy-global`，国内与国际账号不会混入同一个号池；在账号页面先筛选平台时，弹窗会默认选中该平台。登录入口不依赖已有账号：默认启动时即使从未登录过国际版，也会保留国际版空账号池与入口。显式单平台或平台列表配置只展示所选平台，缺少某个入口时请检查[多平台配置](configuration.md#多平台配置upstreamplatforms)。凭证自动落盘，号池每 10 秒扫描一次目录，无需重启。未配置目录时分别使用 `~/.workbuddy` / `~/.workbuddy-ai`。

国际版设备登录使用 `agent2api login -region global -out auths/global/account-a.json`。同时管理两个区域时，请显式配置不同的 `accounts_dir`，见[双平台配置](configuration.md#多平台配置upstreamplatforms)。不要混放两种区域的凭证。

### 调度语义

| 情况 | 行为 |
|---|---|
| 日常调度 | 按账号**健康度加权随机**选号，健康者更易被选中但不被独占；同一会话**粘住同一账号**，长上下文不在账号间漂移 |
| 并发压力 | `max_concurrency_per_account` 默认 **0（不限）**；显式设为正数时，达到上限的账号不再被选中，所有账号满载后请求**排队等槽位**（本地背压）。例如上限为 4 时矩阵显示「2/4」，未限制时显示「2/∞」 |
| 限流（429）且上游给出精确重置时刻 | 只冷却**该账号上的该模型**到指定时刻（封顶 24h）并换号，同账号其他模型不受影响 |
| 限流（429）但无精确重置时刻 | **不锁定**：只降低该账号健康度并换号 —— 避免一次普通限流把账号/模型整体挂起（实测曾出现「一个问题问完，两个号都冷却」） |
| 额度耗尽（14018） | 同样**不锁定**：上游的 credits 是积分倍率而非账号余额，且上游不提供恢复时刻；降健康度换号，同账号的免费/低价模型照常可用 |
| 鉴权失效（刷新后仍 401） | 整号标记 **blocked**（终态，不会自动恢复）—— 这是账号死亡而非限流，反复重试无意义；在控制台「重新登录」或「清除冷却」后恢复 |
| 参数错误（如上下文超限） | 直接失败 —— 换任何账号结果都一样 |
| 传输错误 / 5xx | 换号但不冷却（可能是全局抖动），池级退避加抖动 |
| 该模型全池不可用 | 返回 429 并附**最早**解冻秒数，提示改用其他模型；若全部是鉴权失效则返回 401（重试永远不会成功） |

健康分 = 成功率 EWMA×0.6 + 延迟 EWMA×0.4，连续失败逐次降权，样本少时向中性收缩。精确参数见 [`internal/adapter/pool.go`](../internal/adapter/pool.go)。

控制台「账号」页可运行时干预，无需重启网关：

- **停用 / 启用**：临时把某账号摘出调度
- **清除冷却**：上游提前恢复时手动解冻（也是 blocked 账号的恢复入口）
- **重新登录**：号池文件账号可发起设备码登录；桌面客户端来源的账号应在原客户端重新登录，再按控制台提示处理，保留其原生加密格式
- 每账号的调度状态、登录状态、凭证有效期与用量（落盘持久化）

> 桌面客户端凭证与号池文件可以并存，账号卡片会标注来源。关闭桌面客户端后，网关可继续使用已经载入的凭证，并自行刷新；退出账号、撤销授权或上游使凭证失效则可能中断调用，需要重新登录。网关不会自动重新载入已存在账号的外部凭证变更，按控制台提示处理。
