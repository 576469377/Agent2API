# 控制台视觉规范

[控制台说明](../console.md)

本轮参考 CC Switch 的官方截图与公开组件实现，采用中性色背景、少量暖色强调、统一控件与清晰的资源行布局。实现仍是本项目自己的 HTML、CSS 和 JavaScript，无新增前端框架、远程字体或运行依赖。

参考版本固定为 [`96d636c`](https://github.com/farion1231/cc-switch/tree/96d636ca1009fe7df293fd66f0072d14be2305be)，重点查看了 [主题与设计变量](https://github.com/farion1231/cc-switch/blob/96d636ca1009fe7df293fd66f0072d14be2305be/src/index.css)、[侧栏](https://github.com/farion1231/cc-switch/blob/96d636ca1009fe7df293fd66f0072d14be2305be/src/components/shell/Sidebar.tsx)、[供应商卡片](https://github.com/farion1231/cc-switch/blob/96d636ca1009fe7df293fd66f0072d14be2305be/src/components/providers/ProviderCard.tsx)及[官方界面截图](https://github.com/farion1231/cc-switch/blob/96d636ca1009fe7df293fd66f0072d14be2305be/assets/screenshots/main-zh.png)。截图与当前源码来自不同界面阶段，作为视觉参考，不直接移植组件或样式。

## 布局与颜色

- 浅色背景以白色与浅灰为主；深色以中性炭灰为主。侧栏、工作区、卡片和输入控件采用不同表面层级。
- 主操作与导航图标使用少量暖色；绿色、警示色和错误色用于实际状态。平台区域与目录能力采用中性标签，避免把地区或能力解释为运行状态。
- 页标题 24–26px，主要卡片标题 14–16px，正文与表格 12–13px，次级说明 11–12px。小型数字与时间使用等宽数字。
- 面板圆角 12px，控件圆角 7px；阴影仅用于区分表面。减少整块彩色提示、重复平台标识与全大写装饰性标题。
- 桌面侧栏可收起为图标导航，选择保存在浏览器本地。收起后链接仍保留可访问名称与悬停名称；手机使用原有抽屉导航。

## 资源与指标

- 平台采用横向资源面板，分别显示平台身份、目录数量、就绪 / 启用账号、账号总数、上游地址与路由前缀。提供平台限定的账号与模型入口。
- “已接入”表示适配器已接入，不保证账号可调用；账号就绪数单独展示，不将停用或失效凭证计入就绪。
- 模型目录将路由提示缩短为一行，费率数量采用同一个汇总面板；表格保留完整路由 ID，不重复显示路由中已有的平台 ID。
- 总览继续区分累计指标、分钟趋势和最近记录样本，保持之前的范围选择、空态和数据时间语义。本轮不改变收费信息、调度策略或后端统计。

## 资源列表

资源列表采用连续的工作区：平台与能力筛选、数量摘要、列表标题和表格合在同一个面板中。模型能力用单行文字显示；实际匹配数包含费率筛选，摘要数量仍按平台、能力和搜索条件统计，方便切换费率类型。

模型、账号和调用记录提供“舒适 / 紧凑”列表密度，偏好仅保存在当前浏览器。表格使用独立滚动区域与固定表头，分页留在滚动区域外；区域可通过键盘聚焦，自动刷新保留滚动位置和区域焦点。紧凑调用记录省略重复的请求模型行，完整请求与实际路由仍可在详情查看。

调用记录的模型、账号和时间筛选放在“更多筛选”中；已有筛选会自动展开，并显示启用数量。展开状态在后台刷新时保留。指标条仅计算当前匹配的最近记录样本，不代表累计统计；空样本的成功率和 P95 显示为未知。账号摘要、状态筛选与标签使用相同的就绪判定。

## 样式职责

| 文件 | 职责 |
|---|---|
| `internal/web/static/style.css` | 原有组件结构与功能布局 |
| `internal/web/static/dashboard.css` | 总览页的专用布局 |
| `internal/web/static/workbench.css` | 统一主题、字体、导航、控件与资源页面视觉 |

新增组件应使用现有颜色变量；共享视觉修改集中在 `workbench.css`。避免继续在总览样式中加入全站主题覆盖。网页资源可由独立控制台从磁盘读取，更新界面不需要停止正在使用的网关。
