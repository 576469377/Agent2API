# 控制台视觉规范

[控制台说明](../console.md)

当前方案基于 [控制台调研与优化计划](2026-10-14-console-plan.md)、[ZCode 用量面板参考](2026-10-15-usage-insights.md)及[布局与交互细化](2026-10-16-console-details.md)，检查了 Sub2API、CC Switch、New API 和 ZCode 的公开页面与组件。采用中性工作区、连续指标区域和分组详情。主视图呈现指标、图表与操作；方法说明按需展开，异常提示出现在对应资源旁。实现使用本项目自己的 HTML、CSS 和 JavaScript。

固定参考版本、源码链接及借鉴范围见调研计划。官方截图与当前源码可能来自不同界面阶段，作为视觉参考，不直接移植组件或样式。

## 布局与颜色

- 浅色背景以白色与浅灰为主；深色以中性炭灰为主。侧栏、工作区、卡片和输入控件采用不同表面层级。
- 主操作和选中导航使用中性强调，蓝色用于链接、焦点和数据；绿色、警示色和错误色用于运行状态。平台区域与目录能力采用中性标签。
- 页标题 24px，主要卡片标题与内容 14px，表格和紧凑控件 13px，次级说明 12px；更小字号仅用于标记或图表刻度。小型数字与时间使用等宽数字。
- 面板圆角 10px，控件圆角 7px；阴影仅用于区分表面。减少整块彩色提示、重复平台标识与全大写装饰性标题。
- 桌面侧栏可收起为图标导航，选择保存在浏览器本地。收起后链接仍保留可访问名称与悬停名称；手机使用原有抽屉导航。

## 资源与指标

- 平台资源面板在宽屏并排、窄屏纵向排列，分别显示平台身份、目录数量、就绪 / 启用账号、账号总数、上游地址与路由前缀。提供平台限定的账号与模型入口。
- “已接入”表示适配器已接入，不保证账号可调用；账号就绪数单独展示，不将停用或失效凭证计入就绪。
- 模型目录将路由提示缩短为一行，费率数量采用同一个汇总面板；表格保留完整路由 ID，不重复显示路由中已有的平台 ID。
- 总览继续区分累计指标、分钟趋势和最近记录样本，保持之前的范围选择、空态和数据时间语义。本轮不改变收费信息、调度策略或后端统计。

## 资源列表

资源列表采用连续的工作区：平台与能力筛选、数量摘要、列表标题和表格合在同一个面板中。模型能力用单行文字显示；实际匹配数包含费率筛选，摘要数量仍按平台、能力和搜索条件统计，方便切换费率类型。

模型、账号和调用记录提供“舒适 / 紧凑”列表密度，偏好仅保存在当前浏览器。表格使用独立滚动区域与固定表头，分页留在滚动区域外；区域可通过键盘聚焦，自动刷新保留滚动位置和区域焦点。紧凑调用记录省略重复的请求模型行，完整请求与实际路由仍可在详情查看。

调用记录的模型、账号和时间筛选放在“更多筛选”中；已有筛选会自动展开，并显示启用数量。展开状态在后台刷新时保留。指标条仅计算当前匹配的最近记录样本，不代表累计统计；空样本的成功率和 P95 显示为未知。账号摘要、状态筛选与标签使用相同的就绪判定。

## 样式职责

| 文件 | 职责 |
|---|---|
| `internal/web/static/style.css` | 原有组件结构与功能布局 |
| `internal/web/static/dashboard.css` | 总览页的专用布局 |
| `internal/web/static/workbench.css` | 统一主题、字体、导航、控件与资源页面视觉 |
| `internal/web/static/usage.css` | 用量指标、活动图、曲线与统计说明 |

新增组件应使用现有颜色变量；共享视觉修改集中在 `workbench.css`。避免继续在总览样式中加入全站主题覆盖。网页资源可由独立控制台从磁盘读取，更新界面不需要停止正在使用的网关。

## 运行提醒与详情

总览首屏的运行提醒分别呈现当前需关注账号与最近样本失败，不能将两者合并为持续故障数。入口直接筛选对应资源。核心指标使用同一连续面板，统计口径沿用既有累计与分钟窗口。

账号状态统计可点击筛选；账号与调用记录的生效条件以可移除标签展示，高级筛选收起后也保持可见。页头的主操作位置固定，更新时间与刷新作为次级信息。

调用详情先呈现原始错误及有限的操作建议，再展示耗时与输出、实际路由、Token 和图片处理。通用 400 保持原因未知；登录失效优先于残留身份信息。抽屉中的关联调用入口按记录中的平台隔离；未知图片数量与实测零张分开表示。

## 费率更新与提醒

页面活跃并启用自动刷新时，每分钟使上游目录缓存失效后重新读取费率；数据时间与费率观察时间保持分开。超过五分钟或本次未确认的条目显示未知，旧倍率加“上次”标注。免费变付费及倍率变化在全站显示提醒，按平台和模型隔离，用户确认后关闭。仅提醒模式继续允许付费调用，详细暂停条件与旧网关行为见[模型费率](../console.md#模型费率)。
