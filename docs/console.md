# 控制台

[文档导航](README.md) · [指标口径](metrics.md) · [运行与升级](operations.md) · [故障排查](troubleshooting.md)

默认入口是 [http://127.0.0.1:8787](http://127.0.0.1:8787)。控制台与生成 API 共用一个网关；已有服务在运行时，可用独立控制台预览新界面。

## 页面与任务

| 页面 | 主要用途 |
|---|---|
| 概览 | 累计或分钟窗口的规模、流量、账号就绪与最近样本 |
| 调用日志 | 近期健康、组合筛选、延迟、缓存和单次诊断 |
| 用量分析 | 累计规模、实时请求、UTC 每日趋势和模型分布 |
| 账号管理 | WorkBuddy 授权与号池管理、TRAE 网页登录 / 自动签到 / 积分余额、OpenRouter 密钥验证保存、Cursor 桌面登录检测 |
| 平台连接 | 认证来源、目录状态、平台顺序与路由策略 |
| 模型目录 | 能力、费率、平台限定名和账号可用性矩阵 |
| 模型测试 | 仅测试当前确认免费的平台模型，查看流式回复 |
| 客户端接入 | 配置本机 ZCode、cc-switch、pi 的免费模型；多平台勾选与批量写入；复制三协议地址和示例 |
| 网关设置 | 本地鉴权、有效超时 / 预算、队列和运行期兼容开关 |

页面支持中文 / English、浅色 / 深色 / 跟随系统、侧栏收起及列表密度。Ctrl/Cmd+K 可搜索页面、模型和账号；详情可用 Esc 关闭。目录、账号和本地统计独立加载，慢上游不会让已经取得的统计继续等待。

## 先确认最近是否还在失败

打开“调用日志”。顶部“近期调用”只使用最近 200 条中的近 15 分钟样本，按请求发起时间筛选；累计失败不会被当成当前故障。

- “失败 · 不含取消”和“客户端取消”分别显示，点击卡片直接带着对应时间与状态进入列表。
- 支持成功、全部未成功、超时、限流 / 额度、取消和多次尝试筛选，也可组合平台、模型、账号、协议和搜索词。
- 表格显示完整耗时与首段等待。上方的 P95 和缓存比例只按当前匹配样本计算，显示参与测量的数量。
- 点击行进入详情，查看真实路由、请求编号、排队、每次尝试、首段与最终用量，不从一句模糊错误猜测原因。
- “复制诊断摘要”不包含正文、账号标识、请求头、自由文本错误或文件路径，适合反馈问题。CSV 导出仍包含本地明细，应在自己的环境保留。

取消用中性状态展示，仍保留原始统计。少量样本的 P95 不能解释成全量历史表现；没有测量的等待或缓存值显示“—”。定义见[指标口径](metrics.md)。

## 统计范围

| 区域 | 范围 |
|---|---|
| 概览累计模式 | 网关已经保存的累计指标 |
| 概览 15 / 30 分钟模式 | 相应的真实分钟桶；当前分钟未结束 |
| 用量页首屏 | 全部累计量，不随下方日期 / 平台筛选变化 |
| 每日趋势、环图及模型明细 | 当前所选日期、平台和已保存 / 明确估算的数据 |
| 调用日志、筛选、CSV、样本 P95 | 最近完成的 200 条，时间筛选按发起时间 |
| 实时输出 | 当前请求与页面最近 30 秒采样 |

累计模型和账号分组沿用历史原始标签，可能合并跨平台同名项；每日记录和限定平台的请求筛选按真实平台区分。不要用累计分组反推某一天或某一个平台的精确表现。

数据来源、上游用量、缓存分母、RPM、完整耗时与接收速率的区别统一见[指标与数据口径](metrics.md)。

## 每日趋势与历史覆盖

每日记录按 UTC 日期聚合，保留最多 366 天；近 7 / 30 天包括当前 UTC 日期。实时完成记录按发起日期归集，旧归档日志按完成日期恢复，界面注明 UTC。

图表展示前六个模型与包含其余模型的“其他模型”。隐藏图例只改变曲线，不改变总量或环图。支持鼠标、触屏与键盘方向键读数。

缺少日期的旧累计量不能重建真实日分布；没有 Token 明细的调用仍计入次数，Token 曲线保留缺口。没有记录、实测零值和估算分别处理。旧后端只能用最近样本生成预览时，会在趋势区域明确提示。

## 热力图的每日 / 每周 / 累计

“活动日历”位于主趋势后，默认折叠，展开时才渲染年度格子；展开状态和焦点在刷新时保留。

- **每日**：每个日期对应该日用量。
- **每周**：周日到周六的合计，选择一周查看覆盖的日期。
- **累计**：从当前日历起点累计到所选周，不表示账号余额。

日历沿用当前平台，独立展示年度保留窗口；Token / 调用指标可单独切换。含历史均摊的格子使用估算标记，悬停与详情注明其来源。

## 实时生成

实时区域直接汇总各阶段的请求数，展开后显示模型、阶段、已用时、实际收到的字符数与估算 Token。

上传、等待响应和等待首段输出由后端观测区分；有输出但连续 3 秒没有新字符时显示“等待后续输出”。阶段不代表模型内部推理状态，长时间上传也不应被叫作正在生成。

自动刷新时实时接口约每秒采样；速度按最近 3 秒的实际字符计算，同模型有校准样本时显示 `≈ tokens/s`。实时数据超过 5 秒未更新会标为过期，采样空档断开绘图；“上次测得速度”附完成时刻，不冒充当前速度。

手动刷新、隐藏页面或打开检查界面会暂停相应轮询。重新回到页面后读取新状态，不把旧数据重绘时刻写成新采样时刻。详见[实时阶段](metrics.md#实时阶段)。

## 历史均摊

旧累计量只有总量、缺少真实日期时，可将差额均匀分配到采集前的指定日期，按既定归属计入国内版 `workbuddy/deepseek-v4.1-flash`。默认区间为采集前 30 天。

参与均摊的趋势显示“含历史均摊估算”及估算 Token 数，日历和读数同样标记。这个值不是当日实测。活跃与连续天数只使用实际调用记录，只有均摊数据的模型不生成单次日志。

通过趋势区域的“统计模式”，或“统计口径”中的历史设置，切换“仅实测”并调整日期。偏好只保存在当前浏览器；每次从原始记录重新计算，刷新不会叠加两次。原始快照、累计总量、API 与 Prometheus 保持实际保存值。

## 恢复本地旧统计存档

可在本地 `config.json` 明确指定只读历史来源：

```json
{
  "metrics_history_imports": ["bin/history-archive.json", "bin/old-proxy.log"],
  "metrics_history_log_timezone": "+08:00"
}
```

路径相对进程工作目录。来源只在启动时读取，来源文件不改动；日志时区必须明确填写。只恢复 366 天保留范围内的实际日期记录，不读取 ZCode 会话、正文或凭证。导入结果、源内容指纹和记录指纹随指标落盘，多次启动或重叠快照不会重复导入。

旧 JSON 快照的实际最近记录会进入日历史，其累计总量只单独列示：无法完全确认与当前计数是否重叠时，直接相加会误计。完成日志只能恢复有据可查的调用 / 成败次数，Token 未保存则明确标未知；已有精确快照的日期不再叠加时间戳精度较低的日志，宁可保留部分覆盖，也不重复计算。旧日志按完成日志的落盘日期归集，实时采集仍按请求开始日期归集。

历史来源仅应保存在本地忽略目录（如 `bin/`），不要提交包含真实统计、账号标签、错误详情的存档。

## 不重启正在运行的网关

在仓库根目录另开终端：

```powershell
go run ./cmd/console -listen 127.0.0.1:8788 -upstream http://127.0.0.1:8787 -assets internal/web/static
```

打开 [http://127.0.0.1:8788](http://127.0.0.1:8788)，客户端继续使用 `8787`。控制台从磁盘读取资源，保留网关鉴权与 SSE 转发，不建立第二个号池或统计文件。

新界面无法让旧网关获得后端新能力。升级嵌入式网页和后端时，在空闲窗口切换候选程序，见[运行与升级](operations.md)。

## 模型费率

费率依据当前上游目录，每分钟尝试同步；超过 5 分钟或确认失败时显示未知。`×0.00` 是零积分倍率，不等于无限额度，账号就绪也不代表模型仍有余量。

模型测试和客户端接入只展示确认免费的明确平台路由。模型测试在选项生成、从目录跳转和发送前重新核对，不能靠旧选择或同名裸 ID 使用另一地区的收费版本。没有可确认的免费模型时停止测试，先更新目录。

目录仍可展示其他条目用于比较，不代表它们已被导入客户端。WorkBuddy 的原始 API 不是全局免费拦截器；OpenRouter、Cursor 和 TRAE 另外在各自适配器检查免费条件，见[平台支持](platforms.md#免费与额度的区别)。TRAE 在目录中单列「免费额度」，显示真实积分倍率和近期检查的免费权益。

```powershell
go test ./cmd/console ./internal/adapter/... ./internal/app/...
node --test scripts/test-console-*.mjs

```

自动检查覆盖计算、过滤、缺失值、隐私和流式行为。布局、主题、键盘焦点、展开状态与窄屏仍需在浏览器验证；调研依据和本轮限制见[全仓审查](reviews/2026-10-23-console-and-repository-review.md)。
