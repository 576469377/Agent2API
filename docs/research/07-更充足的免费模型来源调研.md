# 更充足的免费模型来源调研

调研日期：**2026-10-23（北京时间）**。筛选条件为：不购买套餐、不充值、不绑支付方式，可以创建免费的 API Token，能够指定模型，并优先考虑持续恢复的额度。上下文窗口和工具调用能力同时影响能否用于 ZCode 编码。

[调研索引](README.md) · [上一轮账号平台调研](06-免费账号平台接入调研.md) · [当前平台支持](../platforms.md)

实施更新（2026-10-24）：本轮工程范围调整为 Kilo 官方匿名免费通道，见 [Kilo 接入](../kilo.md)。魔搭按用户决定不实施；下文保留当日候选比较，不代表其已接入。

## 接入优先级

**优先验证 Kilo Gateway 和魔搭 ModelScope。** 前者按小时限制免费请求，已有多个明确命名的长上下文模型；后者每日登录赠送魔粒，公开提供包括 DeepSeek 在内的模型 API。NVIDIA 值得继续验证，但公开材料不足以承诺统一总额度。Kiro 按用户决定降低优先级，现有接入保留。

| 来源 | 持续免费额度或限流 | 模型自选 | 对本项目的判断 |
|---|---|---|---|
| **Kilo Gateway** | 免费模型每个 IP **200 次/小时**；不是月赠积分 | 是；本轮公共目录筛出 **14 个明确名称、声明支持工具的免费文本输出模型** | **第一优先**；部分模型 1M 上下文，需处理免费活动到期与目录变化 |
| **魔搭 ModelScope** | 每日登录 **200 魔粒**；绑定阿里云后每日再 **50**；API 要求绑定实名认证云账号 | 是，指定实际提供 API-Inference 的模型 ID | **第一优先**；旗舰档约 **125 次/日**，每日额度须到账，通常以单并发为目标 |
| **NVIDIA Build / NIM** | Developer Program 提供免费开发测试 API；统一总次数与恢复周期未确认 | 是，选择公开 API 目录中的具体模型 | 第二批；先验证新账号实际额度，不承诺“无限” |
| **Cloudflare Workers AI** | **10,000 Neurons/日**，UTC 零点恢复；免费套餐用尽即失败 | 是，但部分新旗舰模型要求付费方式 | 可量化的日常备用；适合 GLM-4.7-Flash 等免费套餐可访问模型 |
| **Groq Free** | GPT-OSS 等当前为 **1,000 次/日、30 次/分钟、8K Token/分钟、200K Token/日** | 是 | 短上下文备用；Token 速率使其不适合作为长上下文主力 |
| **Gemini Developer API** | 部分模型输入输出免费；实际 RPM / TPM / RPD 在 AI Studio 查看 | 是，例如 Gemini 3.8 Flash；不是全部 Gemini 模型 | 账号额度核验后再排序，保留 1M 输入能力的价值 |
| **Mistral Studio Free mode** | 默认免费 API，无须信用卡；公开入门页未给出统一固定额度 | 是，入门例子为 mistral-small-latest | 补充候选，暂不能证明额度比 Kiro 更充足 |

各行的限制来自下文对应官方文档。它们是不同单位，**不能用“200 次”和“50 积分”直接计算倍率**。模型一次工具续轮通常还会产生新的推理请求；一个编码任务不等于一次调用。

本篇在 2026-10-23 调研时尚未注册适配器、添加账号入口或写入 ZCode；后续 Kilo 实施状态见开头更新。当时的实测范围是公开文档、魔搭实际渲染页面，以及 Kilo / OpenCode 的公共模型目录 GET；没有使用候选平台账号进行生成。

## Kilo Gateway

### 免费条件与访问方式

Kilo 官方允许免费模型在无充值、无信用卡情况下使用，并允许从模型选择器直接选定免费模型。网关开放 OpenAI 兼容接口、SSE 和调用方工具协议，免费模型还允许匿名访问；账号方式使用 Kilo 自己的 API Key。[免费模型说明](https://kilo.ai/landing/free-models)、[认证](https://kilo.ai/docs/gateway/authentication)、[接口定义](https://kilo.ai/docs/gateway/api-reference)

免费请求按 **IP 而非 API Key** 限制为每小时 200 次，登录用户和匿名请求均受约束。共享出口下不同客户端会共同使用限制；增加账号不会自然增加容量。文档没有给出固定的月赠积分，**这也不构成无限容量或永久免费的保证**。[用量与计费](https://kilo.ai/docs/gateway/usage-and-billing)

当前官方接口地址为 `https://ai-gateway.kilo.ai/api/v1`。搜索缓存仍能看到旧地址 `https://api.kilo.ai/api/gateway`，实际开发应使用现行文档和验证后的地址。[模型与供应商](https://kilo.ai/docs/gateway/models-and-providers)

## 魔搭 ModelScope

### 每日额度

现行魔粒规则为：每日登录 200 短期魔粒，绑定阿里云后再增 50；短期额度从发放起有效 **24 小时**。首次完善信息、邀请和社区贡献属于其他奖励，不计入基础持续额度。使用魔粒还需完善资料并验证邮箱。[魔粒体系](https://www.modelscope.cn/docs/magicube/intro)

API-Inference 要求绑定阿里云账号且该云账号通过实名认证；因此完成 API 前置条件并获得当天赠送后，基础预算按 **250 魔粒/日**计算。不能假设仅调用 API 就能触发每日登录赠送，领取与到账方式需要真实账号验证。[API 使用限制](https://www.modelscope.cn/docs/model-service/API-Inference/limits)

| 单模型扣减档位 | 每次参考扣减 | 250 魔粒可兑换的调用次数 |
|---|---:|---:|
| 轻量模型 | 0.5 | 500 |
| 主流模型 | 1 | 250 |
| 旗舰模型 | 2 | 125 |

这是按公开档位计算的额度上限，不是实际吞吐保证。余额还可能被生图、视频或训练使用；具体模型扣减以模型页的“魔搭社区” API 报价为准。旧文章的“固定每天 2000 次”已经不适合描述现行规则。

### 模型与编码价值

免费 API-Inference 支持指定完整模型 ID，且与付费外部 API-Provider 分开。官方模型页 `deepseek-ai/DeepSeek-V4.1-Flash-1017` 当前展示魔搭 API 示例及 **2 魔粒/次**；这提供了旗舰模型的具体入口，不仅是小模型目录。[DeepSeek 模型与 API 示例](https://modelscope.cn/models/deepseek-ai/DeepSeek-V4.1-Flash-1017)

模型卡写明原模型 1M 窗口，但该卡同时包含本地部署说明，**还不能据此给魔搭托管端点承诺 1M**。上线前必须验证平台实际输入上限、输出上限和工具续轮，再导出给 ZCode。

接口采用 `https://api-inference.modelscope.cn/v1`，提供 OpenAI Chat 兼容方式；介绍还列出 Anthropic 兼容入口。Responses 支持范围有模型限制，不能因为有一个兼容入口就宣称所有模型支持三种原生协议。[API 介绍](https://www.modelscope.cn/docs/model-service/API-Inference/intro)

平台按实时资源动态限流，目标是保障开发者单并发正常使用；老模型可能下架。这适合个人编码备用，不应承诺固定高并发。只选择带 API-Inference 标识的实际托管模型，权重可下载或能开 Demo 不足以证明具有免费 API。

## NVIDIA Build 和 NIM

NVIDIA Developer Program 官方提供免费的 NIM API 访问，面向研究、开发和原型测试。它与 90 天 AI Enterprise 试用不同，也不同于用户自己购买 GPU 运行 NIM。[官方 FAQ](https://docs.api.nvidia.com/nim/docs/product)

平台可以自选目录中的具体模型，访问入口为 [NVIDIA API Catalog](https://build.nvidia.com/explore/discover)。但 FAQ 没有承诺统一的每日次数、每月额度、永久零价或固定 40 RPM。

本轮查到的“40 RPM”来自开发者论坛的用户提额帖，不能当作官方对所有账号和所有模型的额度保证，也不能证明没有月度或其他限制。[论坛原帖](https://forums.developer.nvidia.com/t/clarity-on-nim-api-free-tier-rate-limit-increases/369624)

因此保留为第二批候选：先核验本人新账号的注册条件、实际免费权益、Key 权限、限流响应和模型端点。免费开发测试用途已确认；“一定比 Kiro 用得久”和“不存在任何总额度”尚不能成立。

## Cloudflare Workers AI

Workers Free 每日含 **10,000 Neurons**，UTC 零点恢复；免费套餐用尽后失败，不自动获得付费额度。Neurons 是平台算力计量单位，不是 Token 或一次对话。[当前定价](https://developers.cloudflare.com/workers-ai/platform/pricing/)

可以自选模型，但当前部分新旗舰需要 Workers Paid 或预付 AI Gateway credits，包括 GLM-5.3 / 5.3-Flash、部分 DeepSeek V4 / V4.1 和 Kimi 版本。这些应从纯免费同步中排除。官方明确举出的免费套餐可访问来源包括 GLM-4.7-Flash、Gemma-4-26B 和 Nemotron-3-120B。[免费模型范围变更](https://developers.cloudflare.com/changelog/post/2026-07-28-models-require-workers-paid/)

以 GLM-4.7-Flash 的当前档位作算术示例：每百万输入 5,500 Neurons、每百万输出 36,400 Neurons，假设一次请求 100K 输入和 2K 输出，约为 **622.8 Neurons**，每日预算约够 **16 次这种长度的请求**。这不是任务数预测，也未包含其他服务消耗或额外推理，实际以平台用量为准。

相较 Groq 的 8K TPM，它可能更适合中等以上历史；但最新旗舰的免费权限较弱。接入需要 Cloudflare 账号 ID 与受限 API Token，具体上下文和工具能力仍应逐模型确认。

## Groq Free

官方免费表当前列出 `openai/gpt-oss-120b`、`openai/gpt-oss-20b`、`qwen/qwen3.8-27b` 均为：**30 RPM、1K RPD、8K TPM、200K TPD**。组织级限制共同生效，先达到任何一项就可能返回 429；账号控制台可能存在不同额度。[免费限流表](https://console.groq.com/docs/rate-limits)

这里的 **8K 是每分钟 Token 预算，不能写成模型上下文只有 8K**。但它会限制大段未缓存代码输入的实际可用性，所以不能仅凭每天 1000 次就把它排成长上下文主力。官方说明缓存命中的 Token 不计入相应速率限制，首次长输入仍需单独验证。

从 Free 升级 Developer 才需要有效支付方式，保持 Free 作为备用即可。[计费说明](https://console.groq.com/docs/billing-faqs)

## Gemini Developer API 和 Mistral Free

### Gemini Developer API

使用正式 Gemini API Key，而不是把 Gemini CLI OAuth 免费权益视为通用 API 权益。当前 Gemini 3.8 Flash 标准输入输出有 Free Tier；Gemini 4 Argon 当前没有免费档。模型名称相近不代表免费权限相同。[官方定价](https://ai.google.dev/gemini-api/docs/pricing)

Gemini 3.8 Flash 模型卡声明输入 **1,048,576 Token**、输出 **65,536 Token**及函数调用，适合关注长上下文的用户。该能力与免费账号实际 TPM / RPD 是不同条件。[模型能力](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash/)

现行限流页要求在 AI Studio 查看项目实际额度，没有统一可承诺的“API 免费 1000 次/日”。保持项目 Free Tier，不绑定付费计费账号；还要核验支持地区和账号资格。[限流](https://ai.google.dev/gemini-api/docs/rate-limits)、[免费与付费状态](https://ai.google.dev/gemini-api/docs/billing/)

### Mistral Studio Free mode

官方入门明确：默认 Free mode 开启 API，无须信用卡；可以创建自己的 Key 并指定 `mistral-small-latest` 调用。[免费 API 开通](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key)

免费用量和速率受限，公开入门页未提供统一固定月额度；不能沿用旧文章“每月十亿 Token”的说法。套餐与 API / Vibe 共享用量，按量计费默认关闭；应先读取账号实际预算和免费模型范围。[套餐](https://docs.mistral.ai/admin/billing-usage/subscriptions)、[Key 与套餐说明](https://docs.mistral.ai/vibe/code/cli/api-keys-profiles)

硅基流动曾有免费模型转收费的记录；合作 App 的内置额度也不等于任意用户持 Key 的同等权益。[免费模型规则](https://docs.siliconflow.cn/docs/userguide/faqs/rate-limit-and-upgradation)、[价格变更记录](https://docs.siliconflow.cn/docs/release-notes/overview)

Qoder 活动要求在桌面客户端领取，API / CLI 直接调用不能代替领取；先确认免费模型权限再考虑工程接入。[每日 100 credits 活动](https://docs.qoder.com/events/100credits)

## 接入与验收要求

本轮工程范围为 **Kilo**，魔搭按用户决定不实施；NVIDIA、Cloudflare 仍保留为调研候选。新平台必须完成同一条产品链路，避免只做后端转发。

| 位置 | 应交付的行为 |
|---|---|
| 添加账号 | 显示各平台独立入口；API Key 与网页登录分开；必要时提示邮箱验证、阿里云绑定等真实前置条件 |
| 免费判断 | 保留上游免费标志、实际零价、赠送额度来源、到期时间和检查时间；资料缺失不默认为免费 |
| 模型目录 | 使用明确平台前缀；过滤 Auto、付费、多媒体非编码及已到期项；变化后撤下失效路由 |
| 上下文 | 分别记录总窗口、输入、输出、速率和平台实际约束；不统一回退到 200K，也不照抄权重模型的 1M |
| 工具调用 | 验证客户端执行工具、结果续轮、并行调用与取消；目录的 tools 标志不足以通过验收 |
| 一键同步 ZCode | 纳入新平台的已确认免费模型；展示实际上下文；保留原有模型、配置备份与写入保护 |
| 限流和额度 | 尊重上游 Retry-After 与共享请求预算；额度不足明确停止，不切收费模型、购买余额或按量端点 |

Kilo 先验证零余额或匿名明确模型的文本 / 工具续轮，再检查到期、非零报价和未知目录分支。魔搭先验证实名认证绑定、当天魔粒到账、指定模型扣减和长历史，再决定免费筛选证据来源。所有新来源都应保留最少的脱敏证据，不把 Key、账号信息和私有代码纳入公开文档。

用量评估应复用同一个隔离编码任务，并控制其他并发流量：分别记录模型请求数、输入 / 输出 / 缓存、任务完成质量、账户额度前后差值及服务端用量。上一次 Kiro 单任务的原生会话计量与账户最终扣减尚有差异，不能把该数值跨平台折算。只有实际完成相同任务后，才适合估算每天或每月能做多少任务。
