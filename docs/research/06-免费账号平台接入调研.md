# 免费账号平台接入调研与实施顺序

调研日期：**2026-10-23（北京时间）**。调研起点：`18d7691`；实施期间保留了后续 `d5b77e5` 的 ZCode 写入保护。本报告区分已经实现、第三方项目宣称支持、源码确认、官方免费权益和本机真实调用验证；这些状态不能互相替代。

[调研索引](README.md) · [当前平台支持](../platforms.md) · [当前架构](../architecture.md) · [开发导览](../development.md)

## 结论

以“普通个人账号、不购买套餐、不充值、不依赖短期新客试用，正常登录后具有免费模型额度”为准，新增来源应优先评估 **TRAE 国内版、Kiro Free、通义灵码个人基础版、Gemini CLI 个人免费档、Codex Free、Devin Desktop Free**。它们的认证、工具协议、实际免费模型和成熟度不同，不能一起标成“开箱即用”。

**当前实施范围：TRAE 国内版与 Kiro Free 已接入；Copilot Free / Student 不实施。** 用户后续明确要求免费账号能够自主选择模型，仅提供 Auto 的来源不接入。下一批候选仍需先核验免费模型自选能力，再评估 Devin Desktop 和灵码个人基础版；Gemini CLI 与 Antigravity 的第三方账号复用限制需要独立处理。Codex Free 可列入候选，但不能将官方客户端免费权益推导成任意第三方应用都有免费 API 权益。

开源网关列出的数十个 provider，混合了订阅账号、收费 API、临时赠金、网页聊天、匿名试用及同一服务的多个地区。**平台数量不是可用的免费来源数量。** 调研起点四个配置 ID 对应 WorkBuddy 两个区域、Cursor 和 OpenRouter，按产品来源是三类；接入 TRAE 国内与 Kiro 后为六个配置 ID、五类来源。

本轮完成版本复查、固定提交的公开源码调查、官方权益核验，以及 TRAE 国内版接入。其余候选保持研究状态。新增适配器进入支持表前，需要免费账号权益响应、实际生成及工具续轮样本；目录文件存在或社区宣称支持都不算验证通过。原网关、WorkBuddy 账号、客户端配置和计费开关未改动。

**实施跟进（2026-10-23）**：TRAE 真实网页授权、个人 Free 权益、三个模型文本 / 原生工具 / 结果续轮已通过；三个下游协议的流式和非流式均已验证。适配器、CLI、控制台和 ZCode 免费筛选已同步接入。Copilot Free / Student 已按最新官方规则确认仅支持 Auto，不满足免费自选模型的要求，未注册适配器、添加账号入口或 ZCode 模型。完整使用与限制见 [TRAE 指南](../trae.md)。

授权成功后默认保存至当前用户的 `.agent2api/trae-cn.session.json`，可用 `-out` 指定独立位置。链接先进入 `127.0.0.1` 的一次性本机入口，再跳转至 `https://www.trae.cn/authorization`，最长等待 30 分钟。授权只向固定 `https://api.trae.cn` 兑换凭据，不接受回调自报的上游地址，不接收用户粘贴 token，不执行签到、充值或生成。CLI 与控制台已支持；浏览器必须与网关在同一电脑，远程浏览器回调尚未实现。凭据到期需重新网页登录。

## 免费的准入标准

| 类型 | 是否纳入主线 | 判定 |
|---|---|---|
| 免费个人账号，额度按天 / 周 / 月恢复 | 是 | 最符合本次目标；有限额度仍算免费 |
| 登录赠送的长期零积分模型 | 是 | 同时确认账号权限与当前模型费率 |
| 免费账号领取日常赠送积分 | 有条件 | 明确说明需要手动领取，区分常态政策和活动 |
| 只有一次新客赠金、14 / 30 / 90 天试用 | 否 | 不能当作持续来源 |
| Plus / Pro / Coding Plan / 学生认证专属 | 否 | 普通用户登录不足以取得这些权益 |
| 免费 API Key，无须充值或绑卡 | 补充清单 | 可以研究，但与“复用客户端登录态”的主线分开 |
| 无账号的免费端点 | 补充清单 | 检查是否是限时推广及是否允许第三方访问 |
| 开源模型、本地推理 | 另一个方向 | 软件 / 权重开放不代表有免费云端算力 |

“免费”不等于无限调用，也不意味着免费档可以访问定价页列出的全部旗舰模型。模型额度、个人套餐、充值余额、按量付费与客户端登录需要分别判断。

## 当前版本复查

### 已经具备的扩展基础

| 已落地能力 | 当前源码 | 对新增平台的要求 |
|---|---|---|
| 三种下游协议与统一 IR | `internal/api/`、`internal/llm/types.go` | 上游适配器转换请求和事件，复用现有协议输出 |
| 跨账号 / 平台共享尝试预算 | `internal/llm/execution.go`、`internal/app/routing.go` | 登录、目录不占生成次数；真正生成统一计数 |
| 有界队列、原子选号与占槽 | `internal/adapter/queue.go`、`pool.go` | 新平台不能另起无限重试或无限队列 |
| 上传、等待、接收的阶段观测 | `internal/adapter/http_trace.go` | HTTP 回调只更新状态，不重新覆盖长流超时 |
| WorkBuddy 长流与稳定会话标识 | `internal/adapter/workbuddy/attempt.go`、`conversation.go` | 平台特有握手保持在适配器内部 |
| 重新登录后更新已载入账号 | `internal/adapter/pool_relogin_test.go` 等 | 不沿用旧版本“重新登录后只能重启”的假设 |
| 实际缓存用量与执行追踪 | `internal/obs/`、`internal/app/live.go` | 上游未报告 Token / 缓存时不能补造数值 |
| 控制台确认免费模型筛选 | `internal/web/static/pricing.js`、`scripts/sync-zcode.py` | 新来源必须同步前后端识别，不能只添加适配器 |

与早期版本相比，当前主要短板已经从基本转发转为**认证扩展、免费权益判定和平台能力描述**。这次不用重做路由或号池。

### 接入前需要统一的接缝

1. 启动装配、定价导出、默认上游地址、管理平台列表和界面提示分散在多个文件；增加一个平台需要多处同步。适合先引入明确的平台描述，包括认证方式、是否支持号池、是否支持设备登录、是否依赖本地客户端。
2. 调研起点 `pricing.js` 与 `sync-zcode.py` 只认可 `upstream_config`、`openrouter_models`、`cursor_free_plan`；本轮新增 `trae_account_catalog`，配合 `trae_free_plan` 的新近账号权益，不从费率快照推断免费额度。
3. 当前免费展示兼容零积分和 Cursor Free，但 TRAE 等使用的是**免费账号赠送积分**。它们可能有正的积分消耗倍率，却不需要花钱；不能简单套用“倍率不等于零就是付费”，也不能把正倍率显示成零。
4. 号池目录扫描、WorkBuddy 设备码登录、Cursor SQLite 和 OpenRouter API Key 是四种不同机制；新平台不能因未识别而落入 WorkBuddy 的凭证扫描与登录分支。
5. 当前默认启动仍应保留现有行为。新候选经验证后按需启用，缺少客户端或未登录不应拖住其他平台启动。

### 三类项目需要分开看

- **订阅 / CLI 网关**：把账号已有的权益转换给其他客户端。Codex、Claude、Kimi Code 常出现在这里，但其中很多需要付费套餐。
- **网页会话反代**：利用网页版聊天会话提供接口。通常只有单一默认模型或 Auto，客户端工具、system、图片及历史都需要额外转换，维护成本高于普通 Chat API。
- **通用 API 聚合器**：New API、LiteLLM 等主要整合持钥的上游。它们支持很多供应商，不代表支持很多“登录即免费”的客户端账号。

因此，“把大项目支持的 provider 全部补上”不是本次的准入规则。

## 主要候选的免费权益与技术价值

### 1. TRAE 国内版：首批，最接近 WorkBuddy

**免费依据**：2026-10-23 再次核对官网，免费用户每月登录赠送 **500 积分**；每日签到 **100 积分**需要另行领取。新用户一次性 2000 积分、邀请奖励和活动折扣不能当作每月固定额度。每日奖励与注册赠金近期有变化，不把旧额度硬编码成账号权益。[套餐与计费](https://docs.trae.cn/ide_plans-and-billing)

**模型**：官方目录包含 DeepSeek、GLM、Qwen、MiniMax、Step、Seed、MiMo 等，但部分模型有会员限制。应读取当前账号目录，不能把官网所有模型写成免费账号都能使用。[当前内置模型](https://docs.trae.cn/ide_models)

**源码依据**：专用 CN 项目区分 Remote 会话和 IDE 原生模型协议；其工具文档也明确区分原生工具与文本桥接。通用 9router 的 TRAE executor 是国际 Remote 路线，不能拿来当国内版通用实现。[CN 工具与端点说明](https://github.com/autumnsentiment/Trae2api-cn/blob/b8f773664a354f2cab82d2531dd8c70d064effe3/README.md)、[9router TRAE executor](https://github.com/decolua/9router/blob/87a74e1bda3677193c6f71a7e2100c90311f0689/open-sse/executors/trae.js)

**已接入范围**：ID 为 `trae-cn`，个人 Free、仅月赠积分，发布 `deepseek-v4.1-flash`、`glm-5.3-flash`、`Doubao-Seed-2.1-Turbo`。三者均已验证文本和原生工具续轮；思考、实际 Token / 缓存按上游报告转回。图片、JSON 模式与 stop 拒绝；max_tokens、采样和思考控制不生效。每次生成重新查权益，付费 / 试用 / 未知积分来源拒绝。签到、新客、邀请赠送来源尚未验证，不自动领取。Remote、会员功能、设备 ID 轮换和未知模型透传未接入。

**首个验收**：文本流 / 非流、真实模型归属、一次客户端工具调用及结果续轮、免费积分耗尽时停止。签到仍由用户在官方客户端手动完成，不与基础接入绑定。

### 2. GitHub Copilot Free / Student：仅 Auto，不实施

**免费依据**：GitHub 当前提供无须信用卡的 Free 方案，有有限的聊天 / Agent AI Credits；支持 CLI，但模型选择是 **Auto**。旧文档的“50 premium requests / 月”属于旧口径，不作为现行固定配额。[当前套餐](https://docs.github.com/en/copilot/get-started/plans)、[官方价格页](https://github.com/features/copilot/plans)

**学生权益复核（2026-10-23）**：学生资格可以获得免费的 Copilot Student 权益，但不等于当前 Copilot Pro 的模型自选能力。GitHub 于 **2026-06-24** 宣布 Free 与 Student 均以 Auto 作为唯一的模型选择方式，当前支持模型文档仍明确这一限制。既有开源代理支持填写模型名，不能作为学生账号现在具有该项权益的依据。[官方变更公告](https://github.blog/changelog/2026-06-24-changes-to-model-selection-for-free-and-student-plans/)、[当前模型与套餐限制](https://docs.github.com/en/copilot/reference/ai-models/supported-models)、[学生免费权益](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students)

**协议路线**：官方 Copilot SDK 调用 CLI server；旧版 `copilot-api` 则是设备授权、Copilot token 与兼容 Chat 接口。当前 AIClient2API 的 Auto 路线已使用 SDK，其代码主动拒绝尚未适配的调用方 `tools`，说明“能 Auto 聊天”不能直接当作“工具完整兼容”。[官方 SDK](https://github.com/github/copilot-sdk)、[Auto 实现](https://github.com/justlovemaki/AIClient2API/blob/8491cb67c5b78cef1b01c6f2e80c60f170f9af92/src/providers/github/github-copilot-core.js)

**接入范围**：按用户新增的“免费且可自选模型”条件，不开发或配置此来源。下述 SDK / server 路线仅保留为技术调研，不代表实施计划；不把 Auto 包装成多个自选模型，也不以 Pro / 企业账号替代免费学生权益验证。

**工程选择**：优先官方 SDK / server 协议；维持 Go 1.23 时应评估边车或独立兼容层，而不是直接增加要求 Go 1.24 的 SDK 依赖。工具需要显式映射回调用方；官方 CLI 内置文件、终端和网络工具不能自动取得网关宿主机权限。[CLI 工具控制](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/allowing-tools)、[Go SDK 依赖](https://github.com/github/copilot-sdk/blob/f2b720c8ec368e035a4d5c72b012fd41b0d533e4/go/go.mod)

### 3. Kiro Free：已通过官方 ACP 接入

**免费依据**：官方 Free 为每月 **50 credits**，周期恢复，Free 不提供增购积分。当前免费模型范围为 Claude Sonnet 4.5 和部分开放权重模型；不能把付费 Auto / 最新 Opus 的目录直接推广给 Free。[定价与免费模型脚注](https://kiro.dev/pricing/)、[周期与增购规则](https://kiro.dev/docs/billing/)

**认证与路线**：Google / GitHub / AWS Builder ID 的个人账号与企业 Identity Center 应分开。私有反代项目常读取 IDE JSON 或 CLI SQLite 凭证；另一条路线是官方 `kiro-cli` ACP，账号留在原客户端。[私有网关参考](https://github.com/jwadow/kiro-gateway/blob/a5292ca04c7c6231e0b47673ac3f981f5a706e1e/README.md)、[ACP 桥接参考](https://github.com/ankitcharolia/kiro-gateway/blob/49f3204a389117bbf67bfe83b59a9d06d2ca678c/README.md)

**已验证实现（2026-10-23）**：Windows 官方 CLI 2.33.1，Google 登录个人 Free。实际账号目录提供 DeepSeek 3.2、MiniMax M2.5 / M2.1、GLM-5、Qwen3 Coder Next，未出现 Sonnet，因此不添加 Sonnet。通过官方 ACP 选择明确模型，专用 Agent 仅启用调用方 MCP 工具；真实文本、工具调用与结果续接均已通过。添加账号提供三种官网登录方式、检测现有连接与积分余额；一键同步 ZCode 保留真实倍率和账号上下文。最大输出未公布，Token 未报告，不能编造；ZCode 8192 为建议预算。见 [Kiro 指南](../kiro.md)。

**具体边界**：Kiro 官方价格 FAQ 明确区分原生 / ACP 支持与绕过原生接口的第三方 harness。应优先研究官方 ACP，不能因为已有私有反代源码就默认选择 token 直连。ACP 也不天然等于 OpenAI 客户端工具协议；需要验证工具注册、结果回传和宿主工具隔离。额度为 credits，不是固定 50 条问答。

### 4. 通义灵码个人基础版：免费真实，个人能力仍需核验

官方价格页明确列有**个人基础版免费**；其中 AI 程序员 Beta 存在 50 轮 / 月等特定限制，个人专业版则是“限免”，不能混为永久免费高级档。[官方价格页](https://lingma.aliyun.com/lingma/pricing)

现有 `lingma-proxy` 支持远端和 IPC，但维护者明确说截图 / 模型基于企业环境，并提示部分 VS Code 插件只支持目录发现，缺少完整 session RPC。由此只能确认技术路线存在，不能确认普通个人免费账号具有同等模型或完整工具能力。[账号与运行时边界](https://github.com/Lutiancheng1/lingma-proxy/blob/ede45575260a1e66c4c43fb2d767de05b1e02958/README.zh-CN.md)

建议 ID 为 `lingma`，先验证个人基础版；QoderCN、旧 Lingma 桌面和企业租户不能混用同一认证 / 目录假设。远端 SSE 暂无独立 thinking 时，不应伪造推理流。

### 5. Gemini CLI 个人免费档：有免费额度，但存在明确第三方限制

官方现行文档仍提供 Google 个人账号免费登录，最大 **1000 次模型请求 / 用户 / 日**，与 CLI / IDE Agent 共享约束；单个用户任务可能包含多次模型请求，不等于 1000 个完整任务。多数个人账号不需要 Cloud 项目。[官方配额](https://geminicli.com/docs/resources/quota-and-pricing/)、[认证方式](https://geminicli.com/docs/get-started/authentication/)

因此，9router 英文首页“Gemini CLI free tier discontinued”的说法不能作为本项目结论。但 Google 官方 FAQ 同时明确限制第三方软件复用 CLI OAuth 后端；免费权益存在与第三方网关适用性是两个独立问题。[官方 FAQ 源码](https://github.com/google-gemini/gemini-cli/blob/451a02ff03f1d2a8fe870c120fd5342cfd6f9fd1/docs/resources/faq.md)

建议保留为 `gemini-cli` 调研项，先确认适用集成途径，再处理 Code Assist 项目发现、Free tier 核验、工具 ID / thought signature 和流式用量。不能自动切到 API Key / Vertex 计费，也不能对免费个人账号开启 AI credits overage。

### 6. Codex Free：官方客户端免费，第三方范围须另证

OpenAI Docs 当前价格页明确 Codex 包含在 ChatGPT Free 计划中，免费档用于短小任务。没有给 Free 提供可据以承诺的统一固定消息数。[官方现行价格页](https://learn.chatgpt.com/docs/pricing)

CLIProxyAPI 有 Codex OAuth 适配；它的存在证明有人实现了该转换，不证明所有模型都向 Free 开放。OpenAI 2026 DevDay 的第三方“Sign in with ChatGPT”推理权益明确提到符合条件的 Plus / Pro，不能将它等同 Free 的 Codex 客户端权限。[官方第三方集成说明](https://learn.chatgpt.com/docs/whats-new/devday-2026)

建议 ID 为 `codex`，后续先确定官方客户端 / SDK 的适用路径，验证真实 Free 计划、可用模型与 credit 使用开关；不导入当前正在使用的付费账号充当免费验证。Responses 事件、reasoning、工具历史和用量需单独适配。

### 7. Devin Desktop Free / 原 Windsurf：新增独立候选

当前 `windsurf.com/pricing` 会跳转 Devin 价格页。官方 Free 为零美元，有有限 Agent 额度、有限模型、无限 Tab / inline edits；**“Free use of SWE-2”列在 Pro 权益里，不能把它算作 Free 的无限模型服务**。[当前价格页](https://devin.ai/pricing)

CLIProxyAPI 已有 Devin 的认证和私有 Connect-RPC 处理。可以研究 `devin`，但桌面 Free 与付费 Cloud / API 是不同产品。必须先验证真实 Free 模型和目录，不能继续按早期 Windsurf 的“25 prompt credits / SWE-1 Lite”资料实现。

### 8. Antigravity：免费档存在，暂不排入首批

官方个人档为 $0，普通免费账号按周恢复基础额度。**2026-10-23 的模型表**中 Gemini 3.8 Flash 向 Free 开放；部分旧 Claude / GPT-OSS 免费项已预告在 **2026-11-02** 移除。最新 Gemini 4 Argon、Sonnet / Opus 5.5 并不属于普通 Free。[套餐](https://www.antigravity.google/docs/plans)、[模型分档与退役日期](https://antigravity.google/docs/models)

官方 FAQ 还明确限制第三方访问与将 `agy -p` 包装进消费账号的第三方 Agent。即使选用 headless，也不能直接当成官方允许的通用免费网关路线。[官方集成限制](https://www.antigravity.google/docs/faq/)

它是“其他项目常接什么”的重要答案，但对本项目应保留为受限制候选，不能作为稳定免费 Claude 来源承诺给用户。

## 接入设计

### 免费权益与费率分别建模

建议保留上游原始费率，额外提供独立的访问权益元数据：

```json
{
  "access": {
    "basis": "recurring_free_allowance",
    "plan": "free",
    "overage_enabled": false,
    "checked_at": "<实际检查时间>"
  }
}
```

这些字段已在 TRAE 的 `ModelInfo.access` 实现，另含 `source` 与 `remaining_credits`。其他来源没有统一实现时不补造数据。`basis` 区分周期赠送与其他免费依据；不知道的值不能默认为免费。控制台与 ZCode 已同步筛选，保留 WorkBuddy 原有统计和 TRAE 的真实积分倍率。

生成前的判定至少包括：真实账号计划、当前模型权限、免费额度来源、是否允许超额消费及观察时间。检查失败或过期时拒绝生成；额度耗尽直接报错，不切换到付费套餐、充值余额、收费模型或其他收费端点。平台前缀继续固定来源。

### 平台接缝

| 位置 | 预计改动 |
|---|---|
| `internal/adapter/<platform>/` | 认证、权益、目录、请求、事件、错误、真实脱敏样本测试 |
| `cmd/agent2api/accounts.go` | 按认证方式装配；避免进入错误的 WorkBuddy 号池路径 |
| `internal/config/config.go` | 独立配置 / 凭证来源与继承规则，不跨平台带入密钥或上游地址 |
| `internal/app/hub.go`、`api.go` | 默认地址、运行描述、模型能力、可选账号操作 |
| `cmd/agent2api/pricing.go` | 正确导出目录 / 免费权益；不通过聊天猜价格 |
| `internal/web/static/pricing.js`、`operations.js` | 识别权益依据、认证方式与适用操作 |
| `scripts/sync-zcode.py` | 只同步已确认的明确平台免费路由，声明真实能力 |
| 用户指南 | 当前支持、配置、登录恢复、限制及验证范围 |

先以可选接口或平台描述表收口公共能力，不把所有新平台强塞进同一种账号池。第一轮没有必要重写已经稳定的三协议、指标与执行记录。

### 工具与 Agent 协议

- 优先保持原生工具 schema、调用 ID、参数和结果关联；工具由 ZCode 等调用方执行。
- 如果采用官方 Agent CLI / SDK，默认隔离其内置终端、文件与网络工具。向客户端返回 `tool_calls` 和在服务器运行工具不是同一件事。
- 文本工具桥接单独标注能力。模型说“文件已写入”不能当作客户端执行成功。
- ACP 需处理初始化、认证、session、增量、权限请求和取消；不能仅将历史拼成 prompt 就宣称完整兼容。
- 未支持的图片、采样、JSON、tool choice、思考参数应给出明确错误或已记录的降级，不能静默丢弃。

## 首批交付与验证门槛

### TRAE 国内版

1. 只读确认本机官方登录态和版本，不打印 JWT / 刷新令牌，不修改设备标识。
2. 读取个人账号模型与积分权益，区分月赠、奖励和购买来源；模型与计费结果不明时停止。
3. 先完成受控的文本流 / 非流验证，再验证原生工具调用与结果续轮；Remote 文本桥接作为独立能力。
4. 捕获最少的已脱敏成功 / 拒绝 / 额度耗尽样本，编写 IR 金帧回归。
5. 同步配置、控制台、ZCode 和文档；通过后才加入已实现列表。

### Copilot Free 历史备选方案（当前不实施）

1. 使用本人普通 GitHub Free / Copilot Free，按官方登录流程准备客户端。
2. 通过现行接口确认 Free 和 Auto 权益，不使用另一个 Pro / 企业账号替代验证。
3. 确定官方 SDK / CLI server 与 Go 1.23 的兼容方案，验证取消时子进程 / 会话可以回收。
4. 先完成 Auto 文本，再单独完成调用方工具协议；在未支持工具阶段不得标记 `supports_tools=true`。
5. 免费额度耗尽、鉴权失效、未知套餐、模型自选、额外付费和重复尝试均有拒绝回归。

### 共用验收

| 测试面 | 必须覆盖 |
|---|---|
| 免费判定 | Free、Paid、Trial、Enterprise、缺少计划字段、目录过期、检查失败 |
| 额度 | 正常额度、明确耗尽、按量开关、来源未知，不自动升级或扣购买余额 |
| 模型 | 明确平台、裸名、别名、权限目录外 ID、未知模型、Auto 的真实归属 |
| 会话 | 两轮文本、工具调用 → 结果 → 汇总、并行工具、模型切换 |
| 内容 | system、长历史、图片、thinking、参数拒绝，无静默历史裁剪 |
| 流 | 首事件拒绝、中途错误、无最终用量、客户端断开、上游空闲、正常结束 |
| 预算 | 生成计数接入共享预算，登录 / 目录不占次数，接受流后不重放 |
| 隐私 | 不记录凭证、正文、真实用户标识；上游错误脱敏 |
| 产品 | 三协议、账号来源、费率依据、ZCode 免费同步与导出 |

最初只确认 `.copilot` 和 TRAE CN 目录存在；**目录存在不证明已登录或拥有免费权益**。后续在用户授权范围内检查了 TRAE 的原有设备标识和过期状态，再按用户偏好完成官方网页登录；新凭据独立保存，不覆盖桌面登录态。已使用该普通 Free 账号进行真实生成，Copilot 仍没有免费账号生成证据。凭据和原始抓包未进入公开材料。

## 本轮验证和保留项

- 本地当前版本通过 `go test ./...` 与 `go vet ./...`。下载的公开参考源码已放在被忽略的独立研究模块中，避免进入项目的 Go 包扫描。
- 固定提交、免费政策和文档冲突均记录在本报告；没有把社区宣传的“免费 / 无限 / 全模型”直接当成结论。
