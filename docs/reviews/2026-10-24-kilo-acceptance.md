# Kilo 接入与免费调用验收

[Kilo 指南](../kilo.md) · [平台支持](../platforms.md) · [客户端配置](../clients.md)

验证日期：2026-10-24（北京时间）。工程范围为 Kilo；魔搭按用户决定不实施。

## 已交付的链路

- 添加账号弹窗提供 Kilo 匿名免费连接检测，单账号状态卡不使用 WorkBuddy 号池，不创建凭证或接受上游密钥。
- 当前公共目录按明确免费、全部零价、具体模型、有效期、文本及工具能力筛选。14 个合格模型进入模型页与三个客户端的一键配置。模型数量随上游目录变化。
- 每次生成和工具续轮重新核验免费状态；上游始终不带账号、组织或 BYOK 凭据。目录失败、转收费或活动过期时拒绝生成；不启用付费回退。

## 真实模型调用

独立服务直接连接 Kilo 官方匿名入口，针对 14 个模型、三种下游协议完成 42 项模型 / 协议验收尝试；24 项完成普通文本、真实工具调用和结果续轮。4 个模型在三种协议全部通过，11 个模型至少在一种协议完成真实工具往返。其余条目不标记为成功。

文本使用随机标记；工具参数包含随机种子。收到真实调用之后才生成另一个随机结果并返回，要求最终回复准确复述。Responses 另验证 MCP 函数命名空间。初次独立匿名调用的上游用量为 `cost: 0`、`is_byok: false`，源代码和离线断言进一步核验不发送鉴权。

## 控制台与配置保留

- 在独立服务使用实际安装客户端配置的隔离副本，真实点击添加账号、ZCode、cc-switch、pi 以及批量配置按钮。检测返回 14 个模型；cc-switch 写出 28 条 Claude Code / Codex 供应商，pi 写出一个包含 14 个模型的供应商，ZCode 写出 14 个模型。
- cc-switch 既有供应商与其他全部业务表逐表对比保持一致，包括当前选择、设置、历史、会话游标和故障转移。pi 其他供应商保留。
- 三个控制台入口重复点击均返回已是最新，不重写或增加备份；CLI 同步显式指向测试地址时也与控制台配置一致。
- 隔离测试没有修改真实 ZCode / pi 配置；备份和证据只留在忽略的本机验收目录，公开文档不包含账号、密钥、原始上游请求 ID 或私有提示。

## 离线回归范围

包括免费标志与零价冲突、所有价格字段、过期 / 未知到期日、Auto / Router、重复 ID、非工具模型、价格变化后的生成拒绝、跨平台配置隔离、无鉴权和重定向拒绝、限流范围、取消、工具结果及命名空间关联、三协议两种输出模式，以及客户端配置写入与到期保护。

与历史图片复用优化合并后的独立源码快照已通过全部 20 个 Go 包测试、`go vet`、Windows 构建、134 项前端检查和 50 项 Python 检查；文档检查覆盖 49 个文件、533 个本地链接，零问题。提交前另外检查源码快照与暂存区中的凭据泄漏；在线 CI 结果独立于本机验收。
